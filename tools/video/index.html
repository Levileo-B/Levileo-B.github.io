视频链接解析

粘贴视频页面地址，拿到规范链接、嵌入代码、封面直链和下载命令

先说清楚这个工具不做什么：它不会替你破解出视频的真实流地址。 浏览器受同源策略限制拿不到那些接口，而且各平台直链都带签名、有时效，必须在服务端解密 —— 静态站点没有后端，做不到这件事。 所以这里做的是链接解析：认出平台和视频 ID，生成规范链接、播放器嵌入地址、 公开的封面图直链，并把 yt-dlp 命令拼好给你，真正的下载交给本地执行。

支持 YouTube、哔哩哔哩、Vimeo、X / Twitter、抖音、TikTok。 没装 yt-dlp 的话：pip install -U yt-dlp 或 brew install yt-dlp。 请只下载你有权保存的内容，并遵守各平台的服务条款。
