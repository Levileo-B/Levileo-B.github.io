视频链接解析

粘贴视频页面地址，拿到规范链接、嵌入代码、封面直链和下载命令

哪些能一键下载：直接是媒体文件的链接（.mp4/.jpg 等）、GIPHY、Reddit 的视频与图集、以及各平台的封面图 —— 这些都能拿到真实直链，点「下载」即可保存。
哪些不能：YouTube、哔哩哔哩、抖音的视频本体。 它们的流地址带签名且有时效，必须服务端解密，静态页面做不到。 这类请用下方拼好的 yt-dlp 命令，或配置一个自建解析服务。

可选：接入自建解析服务，让平台视频也能一键下载

填入一个接受 POST {"url": "..."} 并返回 {"url": "直链"} 的接口地址（cobalt 自建实例即为此格式）。地址只存在你自己浏览器的 localStorage 里，不会上传到任何地方。 留空则不启用。

支持 YouTube、哔哩哔哩、Vimeo、X / Twitter、抖音、TikTok。 没装 yt-dlp 的话：pip install -U yt-dlp 或 brew install yt-dlp。 请只下载你有权保存的内容，并遵守各平台的服务条款。
