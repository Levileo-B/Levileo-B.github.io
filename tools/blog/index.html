怎么把文章发到这个站点上

这个编辑器只负责写作和导出，不会替你提交代码 —— 那需要 GitHub 令牌， 而把令牌存进网页是不安全的。发布流程建议这样： 先「下载 .md」拿到文件，然后在仓库里新建 posts/你的文件名.md 并粘贴内容， 直接用 GitHub 网页版的「Add file → Create new file」就能完成，不用装任何东西。

支持的语法：标题、加粗、斜体、删除线、行内代码、围栏代码块、 有序 / 无序列表、引用、分隔线、链接、图片。暂不支持表格和脚注。 正文里的原始 HTML 会按纯文本显示，不会被执行。
